## 視窗感知與標題列吸附

- **DWM 視窗框追蹤**：找到使用中的 `Claude.exe` 主視窗（支援 Windows Store MSIX 與一般 Squirrel 安裝，並排除背景的 `claude-code` CLI 程序），用 `DWMWA_EXTENDED_FRAME_BOUNDS` 讀取邊界，所以 Clawd 能以 0 px 間隙坐在標題列上。
- **「思考中」推測**：只量 Claude 視窗本身與其網路服務子程序的 I/O（持續 ≥ 8 KB/s），不量 renderer、GPU 程序、node／MCP 子程序，也不量終端機裡的 Claude Code。
- **攀爬與閒逛**：Clawd 會在工作列上走動、沿著 Claude Desktop 視窗側邊爬上去，坐在標題列上往下偷看你的對話。
- **視窗物理**：
  - 以一般速度拖動 Claude Desktop，Clawd 會跟著移動。
  - 視窗最小化或關閉時，Clawd 自由落體掉下（`FALLING` → `LAND_SQUISH`）。
  - 快速甩動視窗，Clawd 會沿拋物線被甩飛（`THROWN` → `DIZZY`，頭上繞星星）。

## 掏筆電打字與工作節奏

Claude Desktop 在思考或產生回答、Claude Code 在忙，或你**雙擊** Clawd 時，牠會從肚子裡掏出一台 `8×2` 的超薄筆電，跳起來把筆電**重摔**成側面的 `\_` 形狀（帶衝擊火花），再伸出兩隻長手臂猛敲鍵盤。

打字是一段一段的，中間會休息：

| 模式 | 每段長度 |
| :--- | :--- |
| 安靜 | 20–40 秒 |
| 標準 | 14–28 秒 |
| 過動 | 8–16 秒 |

休息從行為設定檔的 `work_breaks` 抽一種：**伸懶腰**、**托腮思考**（頭上「…」）、**喝一口熱咖啡**，或從筆電上抬頭看一眼。伸懶腰與喝咖啡有冷卻時間，不會連續出現。有 subagent 在跑時，休息改成[拋球](claude-code-hooks.zh-TW.md#hook-事件)。

只有 Claude Desktop 的 I/O 推測訊號時，最多連續打字 60 秒，之後 90 秒不理會這個訊號（Claude Code 的 hooks／transcript 不受影響）。回合結束後 8 秒內也會忽略 Desktop 的 I/O 尾巴，免得又開始打字。

## 收筆電／踢飛筆電

- **安靜／標準模式**：闔上筆電、拿起折好的筆電塞回肚子，再拍拍肚子（`put_away_laptop`）。
- **過動模式**：抬腳蓄力，**把筆電一路踢過桌面撞上螢幕左緣（`x = 0`）**，觸發 14 幀（1.75 秒）的像素爆炸：短路電光 → 火球與飛散的鍵帽 → 連鎖爆炸 → 濃煙 → 金色 `★`。

## 系統匣

Clawdlet 常駐在 Windows 系統匣（`clawdlet.ico`）。雙擊圖示會把 Clawd 召喚回畫面中央；右鍵選單：

- **召喚回畫面中央**會重新[登場](#登場)；**召喚至 Claude 視窗**一律掉到 Claude 的標題列上。
- **掏出筆電打字**：切換打字，和雙擊 Clawd 一樣。
- **邊緣躲藏**（[見下方](#邊緣躲藏)）、**允許推視窗**（[見下方](#允許推視窗)）。
- **離開時送信**、**打字時聆聽**、**需要我時通知**：預設全開，但不會記住上次的設定；想一啟動就關掉，用 `--no-mail`／`--no-listen`／`--no-notify`。
- **安裝／更新 Claude Code hooks**、**複製 Claude Code hook 設定**：見 [Claude Code hooks](claude-code-hooks.zh-TW.md)。
- **重新載入行為設定**、**開啟設定資料夾**：見[行為設定檔](behavior-config.zh-TW.md)。
- **活躍度**：安靜／標準／過動模式。
- **縮放比例**：1x（64 px）／2x（128 px）／3x（192 px），以腳底為錨點。
- **穿透鎖定模式**（`WS_EX_TRANSPARENT`）：滑鼠點擊會直接穿過 Clawd。
- **顯示除錯資訊**：即時狀態與 HWND 資訊列。
- **結束 Clawdlet**：Clawd 會先[揮手道別](#道別)。

## 對你有反應

### 游標感知
休息時眼睛會跟著游標轉，偶爾小跑步到游標正下方；過動模式下，游標停在牠頭上方不動時會**撲上去**。

### 觸摸與連擊
單擊**戳一下**，不按鍵、滑鼠在牠身上左右來回摩擦就是**摸摸**（冒愛心），快速連點三下以上會**抓狂跺腳**。單擊與雙擊要等系統的雙擊間隔（最多 0.5 秒）過後才判定。

### 作息與睡眠
90 秒沒碰鍵盤滑鼠就打哈欠睡著（`Zzz`），一有動靜就驚醒。

### 邊緣躲藏
系統匣開關。開啟後 Clawd 會躲在最近的螢幕邊緣只露出一半，游標靠近時探出身體揮手。

### 分層閒置
你離開越久，Clawd 做的事越多：

- **L1**：休息時偶爾左右張望、眨眼、看向 Claude 視窗（坐在上面時就往下看）。純外觀。
- **L2**（45 秒沒操作）：攤開**卷軸**來看（看完常接著**擦爪子**），或在地上**挖沙**。
- **L3**（90 秒）：打哈欠 → 睡覺，L2 動作做到一半也會直接睡著。

### 位置感知動作
- 在 Claude 標題列的兩端，可能面朝外坐著、**雙腳懸空晃來晃去**。
- 游標在視窗內時，可能探出身體**往下看**游標。
- 走到螢幕邊緣卻沒爬上去時，有時會先**抓抓牆**再轉身。
- 走到 Claude 視窗側邊時，可能先**敲一敲**再爬上去。

分層閒置與位置感知動作都是[行為設定檔](behavior-config.zh-TW.md)裡的列（`read_scroll`、`polish_claw`、`dig_sand`、`perch_dangle`、`perch_peer`、`edge_scratch`、`window_drum`、`fidgets` 列表，以及 `settings.idle_level2_after_s`／`fidget_interval_s`），權重、機率、時長、冷卻都能調，也能關掉。登場方式（`entrances`）與送信前的離開時間（`settings.mail_away_s`）也一樣。

### 登場
啟動時（沒指定 `--spawn`）與按下**召喚回畫面中央**時，Clawd 會從行為設定檔的 `entrances`（eSheep 風格的 spawn 表）抽一種方式登場：

| 登場方式 | 權重 | 說明 |
| :--- | :---: | :--- |
| 掉到 Claude 標題列上 | 5 | 看得到視窗才會抽到；「召喚回畫面中央」不會抽到 |
| 從螢幕頂端隨機位置掉下 | 3 | |
| 從螢幕側邊走進來 | 2 | 多螢幕時，會跳過和其他螢幕相鄰的那一側 |

### 道別
在系統匣選**結束**時，Clawd 會先揮手道別再關閉（最多等 2 秒；在空中、被抓著或爬牆時直接結束）。`Ctrl+C` 與 `--duration` 仍會立即結束。

### 離開時送信
Claude Code 回合結束時，如果你已經離開 30 秒以上（`settings.mail_away_s`），Clawd 會先不慶祝，改成替你保管一封**信**。你回來後（睡著的話會先醒來），牠會帶著信封走到游標旁舉著。**點一下**就能收信：Clawd 把信交給你，**把 Claude Desktop 拉到前景**讓你看回答，然後慶祝。

開始送信後 90 秒沒人收，或同一個 session 又開始忙，信就作廢。送信優先於其他 session 的打字（拋球除外）。可在系統匣或用 `--no-mail` 關閉。

### 打字時聆聽
Claude Desktop 在前景、滑鼠不動而你在裡面打字時，Clawd 會朝視窗歪頭聽；你停手 1.5 秒後恢復原本的動作。

**隱私**：Clawdlet 從不讀取你按了哪些鍵，只知道「有輸入發生」——也就是游標沒動時，`GetLastInputInfo` 回報的系統最後輸入時間一再歸零（點擊或滾輪也會）。不用 `GetAsyncKeyState`、不裝鍵盤 hook，也不保存或記錄任何東西。可在系統匣或用 `--no-listen` 關閉。

### 需要我時通知
Claude Code（終端機或 Claude Desktop 的 Code 分頁）停下來等你時，Clawd 會舉出說明原因的牌子：

| 等待原因 | 牌子 |
| :--- | :--- |
| plan 審核（`ExitPlanMode`） | 打勾的**計畫卷軸** |
| 發問（`AskUserQuestion`、MCP elicitation） | 頭上跳動的 **「?」** |
| 工具授權 | 金色**鑰匙** |

- Claude Desktop 在背景且 10 秒沒回應時，Clawd 會**拿著牌子走到游標旁**並待在那裡；**點一下 Clawd** 就會把 Claude Desktop 拉到前景。Claude Desktop 在前景時牠不會走過來。
- 沒裝 hooks 時，工具呼叫的 transcript 安靜 8 秒只會出現淡色的 **「…」** 泡泡（打字時疊在筆電上方，否則在牠站的地方），不會走過來，30 秒後消失。跑很久的指令看起來也可能一樣。
- 多個 session 同時等待時：授權 > 發問 > plan。
- 可在系統匣或用 `--no-notify` 關閉（hooks 的提示會改回原本的「!」）。

## 允許推視窗

預設關閉。開啟後，過動模式下 Clawd 可能走到 Claude 視窗旁，把它往旁邊推最多 36 px（視窗仍完整留在螢幕內）。最多每 15 分鐘一次，只在你閒置 20 秒以上時發生，最大化的視窗不會被推。任何輸入都會立刻停止。
